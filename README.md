# Áurea Digital

Site institucional da Áurea Digital, com apresentação de serviços e demonstrações de soluções digitais.

## Estrutura do projeto

- `index.html` — estrutura e conteúdo do site principal;
- `style.css` — estilos, responsividade e estados visuais;
- `script.js` — interações e comportamentos do site principal;
- `demo-saude/` — demonstração de uma solução digital para a área de Saúde e Nutrição.

## Execução local

O projeto pode ser visualizado abrindo o arquivo `index.html` diretamente no navegador.

Também é possível utilizar um servidor local de desenvolvimento para acessar o site por um endereço HTTP local.

## Demonstração de Saúde

A pasta `demo-saude` contém uma demonstração visual destinada à apresentação do projeto.

O formulário existente nessa demonstração é apenas uma simulação de interface. Nenhuma informação preenchida é enviada, armazenada ou processada.

## Tecnologias

- HTML5;
- CSS3;
- JavaScript puro.

## Validações

O projeto contempla verificações relacionadas a:

- responsividade;
- navegação por teclado;
- acessibilidade básica;
- funcionamento dos links internos;
- validação sintática dos arquivos JavaScript.
